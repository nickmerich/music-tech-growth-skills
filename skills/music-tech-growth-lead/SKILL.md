# Music Tech Growth Lead

## Step 1: Map the funnel with labels

| Stage | Definition | Number | Label | Source |
|-------|-----------|--------|-------|--------|
| Discover | Saw a demo, post, or listing | | | |
| Visit | Landed on the product page | | | |
| Trial / download | Started a trial or free version | | | |
| Installed | Product loaded in a DAW or app opened | | | |
| First output | Made a sound, track, or export they kept | | | |
| Paid | Purchased or subscribed | | | |
| Kept | Paid minus refunds and chargebacks, past the refund window | | | |
| Referred | Shared, posted, or brought another buyer | | | |

Missing stages are UNKNOWN. Installed and first output are the most often missing and the most important.

## Step 2: Pick one constraint

| Pattern | Constraint | Skill |
|---------|-----------|-------|
| Lots of trials, few installs | Install and license friction | `first-output-activation` |
| Installs, little first output | First-session design | `first-output-activation` |
| First output, low paid | Offer and pricing | `pricing-and-promotions` |
| Low traffic, good conversion | Demand | `demo-and-content-engine`, `creator-recruiting` |
| Partners approved, few posting | Activation | `creator-activation-ladder` |
| Sales but can't tell from where | Measurement | `attribution-and-measurement` |
| Buyers don't stay or upgrade | Retention | `community-and-workshops` |
| Don't know who buys | Research | `music-creator-research` |

## Guardrails

- Organic first unless paid spend is authorized.
- Separate drafted, approved, sent, posted, and verified.
- Keep each product's data, partners, and terms separate from other businesses you work with.
