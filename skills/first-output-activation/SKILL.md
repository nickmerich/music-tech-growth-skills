# First-Output Activation

The first session decides most of it. Measure **time to first sound** and **time to first kept output** (bounced, saved, or exported).

## Step 1: Walk the path yourself, on each supported setup

Download → install → license/activate → open DAW → find the plugin → load → first sound → first useful result. Time each step. Write down every error, rescan, permission prompt, and moment you had to search for help.

Common breakers:
- Platform mismatch (Mac only, Apple Silicon vs Intel, Windows beta). Say supported platforms up front on the product page and in every partner message.
- Format missing for the user's DAW (AU vs VST3 vs AAX).
- DAW didn't rescan; plugin is in the wrong folder.
- License email went to spam, wrong address, or the code was already used.
- Huge library download before any sound.
- Blank first screen with no preset or starter project.

## Step 2: Design the first session

- Open on a preset or starter project that sounds great immediately.
- One obvious first action ("press a key," "drag in a vocal").
- A path to export in under 10 minutes.
- An in-product prompt to save or share what they made.

## Step 3: First-output guide

One page per DAW: install, rescan, load, make one specific thing, save it. Short video version. Troubleshooting for the top five errors.

## Step 4: License handoff for creators and reviewers

1. Verify the recipient (right person, right email) before sending.
2. Send license, installer link, platform requirements, and the first-output guide together.
3. Confirm activation within 48 hours.
4. Confirm a first successful use in their DAW. That's the handoff done, not the email sent.

Track each as: verified → sent → activated → first use confirmed.

## Measure

Trial starts, installs, first sound, first kept output, paid. If your product can't report installs or first output, add lightweight, consented, privacy-respecting events or ask in a day-2 email.
