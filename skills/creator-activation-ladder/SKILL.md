# Creator Activation Ladder

Compute day N from the partner's acceptance date. Each touch has exactly one next action.

| Day | Trigger | Touch |
|-----|---------|-------|
| 0 | Accepted | Welcome: tracked link, code, license status, one action ("post a 20-second before/after this week") |
| 1 | License delivered | Confirm first successful use in their DAW (`first-output-activation`) |
| 3 | No post | Copy-paste hook and caption for their platform and genre |
| 7 | Still no post | Easier format (one Story or Short) plus a 15-minute call offer |
| First post | Post detected | Thank them; reshare with approval; tip on pinning the link |
| 14 | No clicks | Personal note from the founder or growth lead with a niche demo idea |
| 2nd sale | Two qualified purchases | Promote to the next status; personal reach-out; feature them (with approval) |
| 30 | Everyone | Monthly brief: one new use case, one asset |
| 60 | No sale | One reactivation offer, then quarterly nurture |
| 90 | Everyone | Review: promote, keep, or retire; ask top partners what would double their output |

## Weekly check

1. Pull approved partners and acceptance dates.
2. Pull qualified sales from the commerce or affiliate platform. Never infer sales from clicks.
3. List who's due a touch today; draft them.
4. Report:

```
Approved N | posted N | 1+ sale N | 2+ sales N | dormant 60d N
30-day activation x% | median days to first sale n
Due today: [partner] → [touch]
```

## Rules

Status labels are recognition; commission stays as the live terms say. State supported platforms up front. Never promise earnings. Any company approval step required before welcoming a partner happens first and is recorded.
