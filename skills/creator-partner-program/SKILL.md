# Creator Partner Program

Most programs fail at activation, not commission rate.

## Step 1: Get the live terms

Fetch the current program page, agreement, and platform settings. Never work from remembered rates, windows, or payout rules.

## Step 2: Score six layers (1 to 5, with evidence)

| Layer | Check |
|-------|-------|
| Economics | Commission vs margin ceiling; refunds, trials, and stacked discounts handled |
| Attribution | Window, first vs last click, code vs link precedence, trial-to-paid persistence |
| Recruiting | Hand-picked share vs open signups; sources |
| Activation | What happens on day 0, 3, 7, 14, 30, 60 |
| Enablement | Platform-specific copy, assets, a demo they can reuse, one human contact |
| Recognition | Visible status ladder, promotion trigger, perks beyond a higher rate |

Name the weakest two. Fix activation before economics.

## Commission ceiling

```
max commission % = gross margin % - target contribution margin % - promo discount %
```

Run it for the typical order with the typical discount code. If the code and the commission together exceed the ceiling, change one of them (as a proposal).

## Design rules

- One tracked link with the discount built in is easier than a link plus a code.
- Decide and publish which wins when a link and a code conflict.
- Product-embedded sharing (presets, projects, templates that carry attribution) beats links alone.
- Status ladders unlock access: early builds, co-marketing, a direct line.
- Disclosure required in every partner post ([FTC](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides-what-people-are-asking)). Put it in the enablement copy.

## Proposals, not changes

Any change to commission, tiers, windows, payout timing, or eligibility is marked `PROPOSAL` with: what changes, why, the expected effect, and every surface to update (agreement, partner page, platform settings, onboarding copy, existing partner notice).

## Scorecard

Approved partners, 30-day activation (first paid conversion), median days to first sale, share of revenue from the top 10% of partners, partners with 2+ sales, dormant at 60 days.
